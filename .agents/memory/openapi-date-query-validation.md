---
name: OpenAPI date query validation
description: Handling date-time query parameters generated by the RadarOH OpenAPI and Zod toolchain.
---

Express supplies query parameters as strings, but the generated Zod schema for an OpenAPI `date-time` query parameter may expect a JavaScript `Date` object. Validate and normalize the raw ISO string at the HTTP route boundary rather than applying that generated query schema directly.

**Why:** A generated query validator rejected valid ISO date filters before the application-level schema could normalize them, while body and response generation remained correct.

**How to apply:** For future RadarOH endpoints with date or date-time query parameters, verify the runtime generated type against `req.query`. Keep generated response validation, but use an explicit coercing/ISO-aware route schema when necessary.
